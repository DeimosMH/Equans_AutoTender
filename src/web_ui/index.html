This folder is being served as plain files

You are seeing this page because the directory was served with something like python3 -m http.server. The AutoTender UI needs its Python backend (tenders, calculator pipeline, PDF export) - static file serving is not enough.

Start it properly from anywhere:

cd src/web_ui
./run.sh            # or: python3 server.py [port]

then open http://127.0.0.1:8080 (or the port you chose).

The page itself lives in static/index.html; this index.html only exists to catch accidental static serving.
